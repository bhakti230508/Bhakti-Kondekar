# FromChem Solution – AI Building Defect Detection App

## 📱 About the Project

FromChem Solution is an Android application developed to assist with the initial identification of visible building defects using AI-powered image analysis.

The application allows users to capture or upload photographs of building surfaces and analyze possible problems such as:

- 💧 Water leakage
- 🧱 Wall cracks
- 💦 Dampness
- 🌧️ Seepage
- 🏠 Waterproofing-related damage
- 🔍 Other visible surface defects

The project was developed to help make the initial inspection process faster and easier before a technician visits the site.

---

## 🎯 Problem Statement

Identifying building defects such as leakage, dampness, cracks and seepage often requires a physical inspection.

FromChem Solution aims to provide an AI-assisted first-level assessment by allowing users to upload a photograph and receive an analysis of the visible defect.

---

## 🚀 Key Features

- 📷 Capture images using the device camera
- 🖼️ Upload images from the gallery
- 🤖 AI-powered image analysis
- 🔍 Identification of visible building defects
- 💧 Analysis of possible leakage and dampness
- 🧱 Analysis of visible cracks and surface damage
- 💡 AI-generated suggestions based on the detected problem

## 📱 How It Works

1. Open the FromChem Solution application.
2. Capture a photograph or select one from the gallery.
3. Submit the image for AI analysis.
4. The AI analyzes the visible area.
5. The application provides information about the possible defect.
6. The application provides a suggested solution or next step.
